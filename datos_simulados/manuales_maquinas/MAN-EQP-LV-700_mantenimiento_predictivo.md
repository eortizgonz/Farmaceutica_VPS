# Manual predictivo LV-700 — Lavadora de contenedores
Área: Lavado. Límites: 12000 h, 6.0 mm/s, 92 °C, 44 A, 700 RPM y 4.0 bar.

Healthy: verificar temperatura, presión y calidad del ciclo.
Warning: posible boquilla obstruida, bomba degradada, filtro saturado o carga fuera de posición. Revisar circulación, calentamiento y sellos.
Critical: cancelar el ciclo de forma segura, despresurizar y aplicar LOTO antes de intervenir bombas o tuberías.
