# Manuales predictivos simulados

Estos 20 documentos ficticios respaldan el modal **Ver factores**. Cada archivo
corresponde a una máquina registrada en `machines` y se versiona en Git.

Para cargar o actualizar sus embeddings en `sop_chunks`:

```bash
flask --app app ingest-machine-manuals
```

Son material demostrativo y no sustituyen manuales del fabricante, SOP
aprobados, evaluación de mantenimiento ni controles de seguridad industrial.
